---
name: Supervisor hiring workflow
description: Product requirement for supervisor access to candidate search, job publishing, and direct applications.
---

The supervisor role should be able to search candidate profiles like HR, publish jobs, and receive applications for jobs it publishes. Direct application intake is optional per job and should be controlled by the publisher.

**Why:** the user asked to give supervisors a useful hiring workflow rather than a general-purpose applications page.

**How to apply:** Keep supervisor candidate search available in the supervisor dashboard, scope its application list to jobs created by that supervisor, and preserve a per-job control for opening or closing direct applications.
