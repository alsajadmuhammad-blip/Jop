## 🚀 كيفية الاستخدام

### 1. الوصول إلى الصفحة:
```
URL: /admin/add-store
الصلاحية: admin فقط
```

### 2. ملء البيانات:
```
التبويب 1: معلومات المتجر الأساسية
├─ اسم المتجر ⭐
├─ الموقع الجغرافي
├─ وصف المتجر
├─ الإحداثيات GPS
└─ نوع المتجر ⭐

التبويب 2: بيانات صاحب الحساب
├─ اسم الصاحب ⭐
├─ البريد الإلكتروني ⭐
├─ كلمة المرور ⭐
├─ تأكيد كلمة المرور ⭐
└─ رقم الواتساب ⭐

التبويب 3: الإعدادات والخدمات
├─ نوع السوق
├─ الباقة ⭐
├─ خدمة التوصيل
└─ ساعات العمل

التبويب 4: الصور
├─ شعار المتجر (5MB max)
└─ صورة الغلاف (10MB max)

التبويب 5: المراجعة النهائية
└─ التأكيد والإنشاء
```

### 3. الإرسال:
```
عند الضغط على "إنشاء المتجر الآن":
1. التحقق من الصحة
2. رفع الصور (إن وجدت)
3. إنشاء الحساب والمتجر
4. عرض رسالة نجاح
5. التحويل إلى صفحة إدارة المتاجر
```
