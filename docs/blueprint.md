# **App Name**: SookAlJawwal

## Core Features:

- Smart Search: AI-powered search for stores and products using natural language processing. The tool will analyze user queries and infer intent to provide more relevant results.
- Geolocation: Automatically detect the user's location to display nearby stores.
- Store Showcase: Display stores with dynamic open/closed status and key product categories.
- Registration: Enable user registration for customers and store owners with distinct forms.
- Store Dashboard: Provide store owners with a dashboard to manage their profile, products, and business hours.
- Customer Profile: Provide customers with the ability to manage their profile information, order history, and personal details.
- Shopping Cart: Allow customers to add products to a cart and view the subtotal, taxes, and total amount.

## Style Guidelines:

- Primary color: Soft Lavender (#D1C4E9) to give a calm and sophisticated feeling, reflecting trustworthiness and simplicity.
- Background color: Light Gray (#F5F5F5), for a clean, neutral backdrop that highlights products.
- Accent color: Muted Violet (#9575CD), to draw attention to key actions and elements.
- Font pairing: 'Poppins' (sans-serif) for headlines and shorter text chunks; 'PT Sans' (sans-serif) for body text.
- Use simple, modern icons related to each product category. Consider using a consistent line thickness and rounded corners.
- Design a responsive layout optimized for mobile and desktop, ensuring a seamless experience on all devices.
- Add subtle transitions when displaying search results or updating cart items.
