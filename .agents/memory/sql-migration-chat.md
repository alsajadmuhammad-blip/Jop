---
name: عرض ترحيلات SQL
description: تفضيل المستخدم لطريقة تسليم تحديثات SQL التي يجب تنفيذها يدوياً.
---

عند الحاجة إلى تنفيذ ترحيل SQL يدوياً في هذه المنصة، أرسل نص السكربت القابل للتشغيل كاملاً داخل المحادثة، لا تكتفِ بذكر مسار الملف.

**Why:** المستخدم طلب استلام السكربت الذي يحتاج إلى تنفيذه هنا في المحادثة.

**How to apply:** أرفق النص النهائي المطابق لملف الترحيل، واذكر ترتيب تشغيله وأي ترحيلات يعتمد عليها.
