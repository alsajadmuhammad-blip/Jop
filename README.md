# Pharmacy-- 🏥

تطبيق شامل لإدارة الصيدليات والمتاجر الطبية، مبني باستخدام أحدث التقنيات لتوفير تجربة مستخدم متميزة وسهلة الاستخدام.

## � البدء السريع

### 1. إعداد قاعدة البيانات
**مهم جداً**: يجب إعداد قاعدة البيانات Supabase قبل تشغيل التطبيق.

1. **إعداد جدول المستخدمين**:
   - اذهب إلى [Supabase Dashboard](https://app.supabase.com)
   - اختر مشروعك
   - اذهب إلى **SQL Editor**
   - انسخ محتوى ملف `docs/supabase-users-setup.sql`
   - شغّل الكود

2. **إنشاء حساب المشرف**:
   - في **Authentication > Users** → **Add user**
   - Email: `admin@markazi.com`
   - Password: `Admin@12345`
   - احفظ الـ UUID

3. **إضافة المشرف في قاعدة البيانات**:
   ```sql
   INSERT INTO public.users (id, name, email, role) VALUES
   ('UUID_المشرف', 'المشرف العام', 'admin@markazi.com', 'admin');
   ```

📖 **لمزيد من التفاصيل**: راجع ملف [SUPABASE_SETUP.md](SUPABASE_SETUP.md)

### 2. تثبيت المتطلبات
```bash
npm install
```

### 3. إعداد متغيرات البيئة
```bash
cp .env.example .env.local
# عدل القيم حسب مشروع Supabase الخاص بك
```

### 4. تشغيل التطبيق
```bash
npm run dev
```

## 🔧 استكشاف الأخطاء

### مشاكل تسجيل الدخول
**الأعراض**: "فشل تحميل بيانات المستخدم" أو "جدول المستخدمين غير موجود"

**الحل**:
1. تأكد من تشغيل `docs/supabase-users-setup.sql` في Supabase SQL Editor
2. تحقق من إعدادات RLS (Row Level Security) في جدول `users`
3. تأكد من وجود حساب المشرف في Supabase Auth وجدول `users`

### مشاكل قاعدة البيانات
**الأعراض**: أخطاء في جلب البيانات أو حفظها

**الحل**:
1. راجع ملف [SUPABASE_SETUP.md](SUPABASE_SETUP.md)
2. تحقق من متغيرات البيئة في `.env.local`
3. تأكد من صحة URL ومفتاح Supabase

### مشاكل الأداء
**الأعراض**: بطء في التحميل أو استجابة بطيئة

**الحل**:

## 🚀 التثبيت والتشغيل

### متطلبات النظام
- Node.js 18+
- npm أو yarn
- حساب Supabase
- حساب Firebase

### خطوات التثبيت

1. **استنساخ المشروع:**
   ```bash
   git clone <repository-url>
   cd Pharmacy--
   ```

2. **تثبيت التبعيات:**
   ```bash
   npm install
   ```

3. **إعداد متغيرات البيئة:**
   ```bash
   cp .env.example .env.local
   ```

   املأ المتغيرات التالية في `.env.local`:

   ```env
   NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key

   # Firebase (للتحليلات فقط)
   NEXT_PUBLIC_FIREBASE_API_KEY=your-firebase-api-key
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-firebase-auth-domain
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your-firebase-project-id
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-firebase-storage-bucket
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your-firebase-messaging-sender-id
   NEXT_PUBLIC_FIREBASE_APP_ID=your-firebase-app-id
   NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=your-firebase-measurement-id
   ```

4. **تشغيل التطبيق محلياً:**
   ```bash
   npm run dev
   ```

   سيتم تشغيل التطبيق على `http://localhost:3000`
