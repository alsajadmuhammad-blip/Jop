# دليل الاستخدام: إضافة متجر جديد (للمشرفين)

## مقدمة
هذا الدليل يشرح كيفية استخدام النموذج المحسّن لإضافة متجر جديد إلى منصة مركزي بطريقة احترافية وسهلة.

---

## الوصول إلى صفحة الإضافة

### الخطوة 1: الدخول إلى لوحة المشرف
```
URL: https://example.com/admin
الصلاحية المطلوبة: Admin
```

### الخطوة 2: الضغط على زر "إضافة متجر جديد"
في تبويب "إدارة المتاجر"، ستجد زر باللون الأزرق:
```
+ إضافة متجر جديد
```

### الخطوة 3: سيتم نقلك إلى صفحة الإضافة
```
URL: https://example.com/admin/add-store
```

## ملء النموذج بالخطوات

### التبويب الأول: المعلومات الأساسية

#### 1. اسم المتجر ⭐ (مطلوب)
```
- الحد الأدنى: 3 أحرف
- الحد الأقصى: 100 حرف
- مثال: "صيدلية النور الحديثة"
- يجب أن يكون اسماً واضحاً وسهل التذكر
```

#### 2. الموقع الجغرافي (اختياري)
```
- المحافظة والمدينة
- مثال: "بغداد - منطقة الكرادة"
- يساعد العملاء على معرفة موقع المتجر
```

#### 3. وصف المتجر (اختياري)
```
- نص حر يصف المتجر والخدمات
- الحد الأقصى: 500 حرف
- يمكنك ذكر:
  * نوع المنتجات المتوفرة
  * الخدمات الإضافية
  * ساعات العمل السريعة
  * تخصصات المتجر

مثال:
"صيدلية متخصصة في الأدوية والمكملات الغذائية.
نوفر خدمة التوصيل للمنزل والاستشارات الصيدلية المجانية.
الهاتف متاح للاستفسارات والطلبات."
```

#### 4. الإحداثيات الجغرافية GPS (اختياري)
```
خط العرض (Latitude):
- مثال: 33.3128
- القيم بين -90 و +90

خط الطول (Longitude):
- مثال: 44.3615
- القيم بين -180 و +180

💡 نصيحة: استخدم Google Maps للحصول على الإحداثيات الدقيقة
```

#### 5. نوع المتجر ⭐ (مطلوب)
```
اختر من:
□ فعلي (محل فعلي)
  - متجر فيزيائي على أرض الواقع
  
□ إلكتروني (متجر أونلاين)
  - متجر افتراضي عبر الإنترنت
```

### التبويب الثاني: صاحب الحساب

⚠️ **ملاحظة مهمة:** هذه البيانات ستُستخدم لإنشاء حساب الوصول الخاص بصاحب المتجر.

#### 1. اسم صاحب المتجر ⭐ (مطلوب)
```
- الحد الأدنى: 3 أحرف
- مثال: "أحمد محمد علي"
- يجب أن يكون الاسم الحقيقي
```

#### 2. البريد الإلكتروني ⭐ (مطلوب)
```
- صيغة صحيحة: example@email.com
- سيُستخدم لتسجيل الدخول
- يجب أن يكون بريداً صحيحاً ويمكن الوصول إليه
- مثال: ahmed.manager@mail.com

⚠️ تنبيه: تأكد من صحة البريد قبل الإرسال
(سيتم إرسال رسالة تفعيل إلى هذا البريد)
```

#### 3. كلمة المرور ⭐ (مطلوب)
```
- الحد الأدنى: 6 أحرف
- يفضل: استخدام رموز وأرقام وأحرف كبيرة
- مثال: Pass@123

نصيحة الأمان:
✓ استخدم مزيجاً من الأحرف والأرقام
✓ تجنب كلمات شهيرة أو تواريخ سهلة
✓ لا تستخدم نفس كلمة المرور لأكثر من حساب
```

#### 4. تأكيد كلمة المرور ⭐ (مطلوب)
```
- أعد كتابة كلمة المرور
- يجب أن تكون متطابقة تماماً مع الحقل السابق

❌ خطأ شائع: عدم تطابق كلمات المرور
```

#### 5. رقم الواتساب ⭐ (مطلوب)
```
- صيغة: 966501234567
- يبدأ برمز الدولة (966 للسعودية)
- يمكن حذف الصفر من البداية
- مثال الصيغ الصحيحة:
  • 966501234567 ✓
  • +966501234567 ✓
  
هذا الرقم سيُستخدم للتواصل مع صاحب المتجر
والرد على استفسارات العملاء
```

### التبويب الثالث: الإعدادات

#### 1. نوع السوق / النشاط (اختياري)
```
اختر من القائمة الموجودة:
- أدوية وعلاجات
- أجهزة طبية
- مستحضرات عناية
- منتجات صحية
- إلخ...

أو أضف نوعاً جديداً:
1. اكتب نوع السوق الجديد في حقل "أضف نوعاً جديداً"
2. اضغط زر "إضافة"
3. سيظهر الخيار الجديد في القائمة

💡 هذا يساعد العملاء في البحث والتصفية
```

#### 2. الباقة الاشتراكية ⭐ (مطلوب)
```
اختر الباقة المناسبة:
- Basic (الأساسية) - عدد محدود من المنتجات
- Pro (احترافية) - مميزات إضافية
- Enterprise (شاملة) - دعم كامل

كل باقة تحتوي على:
• حد أقصى للمنتجات
• مدة الاشتراك
• السعر
```

#### 3. خدمة التوصيل (اختياري)
```
هل يقدم المتجر خدمة التوصيل للعملاء؟

□ نعم (تفعيل الخدمة)
  - المتجر يوفر توصيل للمنزل
  - سيظهر في البحث المتقدم
  
□ لا (بدون توصيل)
  - الشراء من المتجر مباشرة فقط
```

#### 4. ساعات العمل (اختياري)
```
لكل يوم من أيام الأسبوع:

السبت    09:00 - 22:00   [✓ مفتوح]
الأحد    09:00 - 22:00   [✓ مفتوح]
الاثنين  09:00 - 22:00   [✓ مفتوح]
الثلاثاء 09:00 - 22:00   [✓ مفتوح]
الأربعاء 09:00 - 22:00   [✓ مفتوح]
الخميس   09:00 - 22:00   [✓ مفتوح]
الجمعة   09:00 - 22:00   [☐ مغلق]

كيفية التعديل:
1. انقر على وقت الفتح لتغييره
2. انقر على وقت الإغلاق لتغييره
3. اختر "مغلق" إذا كان اليوم مغلقاً كاملاً

⏰ الصيغة: 24 ساعة
مثال: 09:00 (9 صباحاً)، 14:30 (2:30 بعد الظهر)
```

### التبويب الرابع: الصور

#### 1. شعار المتجر (اختياري)
```
الصيغ المدعومة: JPG, PNG, GIF, WebP
الحد الأقصى: 5 MB

نصائح:
• استخدم صورة مربعة (1:1)
• اجعلها واضحة وسهلة التعرف عليها
• تجنب الخلفيات المعقدة
• استخدم دقة عالية (أقل 200x200 بكسل)

الطريقة:
1. اسحب الصورة إلى المربع أو انقر للاختيار
2. اختر الملف من الحاسوب
3. ستظهر معاينة الصورة مباشرة
```

#### 2. صورة الغلاف (اختياري)
```
الصيغ المدعومة: JPG, PNG, GIF, WebP
الحد الأقصى: 10 MB

نصائح:
• استخدم صورة عريضة (16:9)
• اجعلها جذابة وتعكس طبيعة المتجر
• تجنب النصوص الكثيرة
• استخدم دقة عالية (أقل 1200x675 بكسل)

الطريقة:
1. اسحب الصورة إلى المربع أو انقر للاختيار
2. اختر الملف من الحاسوب
3. ستظهر معاينة الصورة مباشرة
```

## معالجة الأخطاء الشائعة

### الخطأ: "اسم المتجر مطلوب"
```
❌ الحل:
✓ تأكد من إدخال اسم المتجر
✓ لا تترك الحقل فارغاً
✓ استخدم حد أدنى 3 أحرف
```

### الخطأ: "صيغة البريد الإلكتروني غير صحيحة"
```
❌ أمثلة خاطئة:
- ahmed@
- @example.com
- ahmed.example.com

✓ أمثلة صحيحة:
- ahmed@example.com
- store@mail.co
- owner123@email.org
```

### الخطأ: "كلمات المرور غير متطابقة"
```
❌ السبب:
- كتبت كلمة مرور مختلفة في التأكيد
- حروف كبيرة/صغيرة مختلفة
- مسافات إضافية

✓ الحل:
- أعد كتابة كلمة المرور بنفس الطريقة
```

### الخطأ: "حجم الصورة كبير جداً"
```
❌ السبب:
- الشعار أكبر من 5 MB
- الغلاف أكبر من 10 MB

✓ الحل:
- استخدم أداة ضغط الصور (TinyPNG)
- قلل دقة الصورة
- اختر صيغة أخف (WebP)
```

### الخطأ: "فشل رفع الملف"
```
❌ السبب:
- انقطع الإنترنت
- نوع ملف غير مدعوم
- مشكلة في Supabase Storage

✓ الحل:
- تأكد من الاتصال بالإنترنت
- استخدم صيغة JPG أو PNG
- حاول مرة أخرى بعد قليل
```

## بعد الإنشاء

### ماذا يحدث بعد الضغط على "إنشاء المتجر"؟

1. **التحقق من البيانات** (ثانية)
   - التحقق من صحة كل حقل
   - فحص الصور

2. **رفع الصور** (ثوان)
   - تحميل الشعار إلى Supabase Storage
   - تحميل صورة الغلاف إلى Supabase Storage

3. **إنشاء الحساب** (ثوان)
   - إنشاء حساب صاحب المتجر
   - حفظ بيانات المتجر في قاعدة البيانات

4. **التحويل إلى لوحة المتاجر** (تلقائي)
   - ستُرى رسالة نجاح "تم إنشاء المتجر بنجاح!"
   - سيتم التحويل إلى صفحة إدارة المتاجر

### حالة المتجر بعد الإنشاء

```
الحالة الأولية: "قيد المراجعة"

معنى ذلك:
• المتجر تم إنشاؤه لكن لم يتم تفعيله بعد
• لا يظهر للعملاء في البحث
• يمكن للمشرف مراجعة البيانات

التفعيل:
• المشرف يراجع البيانات
• المشرف يضغط على زر "تفعيل" عندما يكون كل شيء جاهز
• المتجر ينتقل إلى حالة "نشط"
```

## الأسئلة الشائعة

**س: هل يمكن تعديل البيانات بعد الإنشاء؟**
ج: نعم، يمكن صاحب المتجر تعديل معظم البيانات من لوحة تحكمه.

**س: هل البريد الإلكتروني قابل للتغيير لاحقاً؟**
ج: نعم، يمكن تغييره من إعدادات الحساب.

**س: كم من الوقت يستغرق إنشاء المتجر؟**
ج: عادة ثوان معدودة، قد يستغرق أطول إذا كانت الصور كبيرة.

**س: هل يمكن إنشاء متعدد في نفس الوقت؟**
ج: نعم، يمكنك إنشاء عدة متاجر على التوالي.

**س: ماذا إذا نسينا كلمة مرور صاحب المتجر؟**
ج: يمكن إعادة تعيين كلمة المرور عبر صفحة نسيان كلمة المرور.
