# Upgrade Next.js to v16 — Summary & Checklist

تاريخ التنفيذ: 2026-02-01

ملخص سريع:
- الهدف: إصلاح ثغرات أمنية متعلقة بإصدارات Next.js القديمة (DoS/Image optimization وServer Actions) وترقية متوازنة إلى Next v16.
- تم إنشاء فرع عمل محلي: `chore/upgrade-next-16` مع تحديث `package.json` إلى `next: ^16.1.6`.

ما تم تنفيذه:
1. تحديث `package.json` لاستخدام `next: ^16.1.6`.
2. تشغيل `npm install` (لم يتم العثور على ثغرات بعد التثبيت في بيئة الاختبار هذه).
3. تشغيل `npm run typecheck` — لا أخطاء TypeScript ظاهرة.
4. تشغيل `npm run build` واجه خطأ CSS متعلق بموقع `@import` (Turbopack صار صارماً أكثر) ➜ تم نقل سطر استدعاء Google Fonts إلى أعلى `src/app/globals.css`، ثم إعادة بناء.
5. البناء نجح بنجاح على الفرع بعد إصلاح CSS.

نتائج وفحوصات:
- البناء: نجاح ✅
- Typecheck: نجاح ✅
- حالة الثغرات بعد التثبيت: لا ثغرات ظاهرة محلياً (تشغيل `npm audit` أظهر انخفاضاً كبيراً؛ إذا أردتم أجرّي مسحًا دوريًا لاحقًا).

الخطوات التالية (مقترحة، مُرتبة ومُوزونة):
1. فتح Pull Request من `chore/upgrade-next-16` → `main` مع وصف التغييرات ولقطات شاشة للبناء الناجح. (ملحوظة: الفرع محلي هنا — يرجى دفعه أو أن أقدّم الـ patch لو رغبت).
2. تشغيل CI (إن وُجد) على الفرع — رصد أي مشاكل في بيئات مختلفة (Node, Linux/macOS).
3. اختبار وظائف حرجة يدويًا: تسجيل/تسجيل خروج، لوحة المتجر، إضافة منتجات، عمليات البحث، وإجراءات الدفع (إن متوفرة).
4. مراقبة أداء واحتياطات التدرج (نشر محدود أو canary قبل الترحيل الكامل).
5. إن نـُشِرت المشكلات، رجوع سهل: rollback إلى الـ main قبل الدمج أو استخدام استراتيجية release/rollback.
