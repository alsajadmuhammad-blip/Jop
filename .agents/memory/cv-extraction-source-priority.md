---
name: CV extraction source priority
description: The expected source precedence for importing a job seeker's CV.
---

Choose exactly one source for CV extraction results: use AI results on success; use automatic extraction only when AI fails. Never merge the two sources, especially their experience lists.

**Why:** Merging can duplicate the same roles and combine unstructured fallback data with organized AI results.

**How to apply:** In the job-seeker "My Profile" CV import flow, determine whether AI succeeded before updating profile state. Replace fallback results with AI output on success; otherwise use the automatic extraction output.
