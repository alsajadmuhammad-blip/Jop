---
name: خصوصية استيراد السيرة الذاتية
description: قرار المستخدم حول عدم حفظ ملفات السير الذاتية الأصلية عند استيرادها.
---

لا تُخزّن ملفات السير الذاتية الأصلية المرفوعة في قاعدة البيانات. استخرج البيانات داخل المتصفح، واحفظ فقط الحقول التي يعتمدها المستخدم.

لتحليل AI الاختياري، يُستخرج النص المهني محليًا ثم يُرسل بعد موافقة الباحث إلى Supabase Edge Function للتحقق والمعالجة، ومنها إلى Cloudflare Workers AI كمزوّد الاستدلال. لا يُرسل ملف PDF/DOCX نفسه. أزل الاسم المعروف والبريد والهاتف والروابط قدر الإمكان، ولا تسجّل النص أو تخزّنه، ولا تحفظ في الملف إلا بعد المراجعة والتأكيد.

خزّن رمز Cloudflare ومعرّف الحساب في أسرار Supabase Edge Functions فقط؛ لا تضعهما في متغيرات `VITE_*` أو المتصفح أو المحادثة. يبقى Cloudflare على Workers Free فقط، بلا ترقية أو دفع تلقائي، ويتوقف التحليل عند استهلاك الحصة اليومية.

**Why:** المستخدم اختار Supabase Edge Function للمصادقة والمعالجة وCloudflare Workers AI للنموذج، مع اشتراط بقاء الخدمة مجانية وعدم حفظ ملف السيرة.

**How to apply:** عند تعديل استيراد السيرة، أبقِ الملف على الجهاز، أرسل النص المنقّى اختياريًا وبموافقة عبر الدالة، وأخفِ أي مفاتيح عن الواجهة. لا تحفظ بيانات الملف قبل تأكيد الباحث ولا تستخدم خطة مدفوعة.
